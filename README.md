# Syed Muhammad Minhal Abbas Rizvi Portfolio

Static portfolio website for AI, cloud, SaaS operations, product strategy, project management, leadership, conferences, academics, and community work.

## GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`.

After the files are committed to the `main` branch:

1. Open the repository settings.
2. Go to **Pages**.
3. Set **Source** to **GitHub Actions**.
4. The site will deploy to:
   `https://minhal-coding.github.io/my-portfolio/`
